# FIRST REAL-DEVICE BASELINE — Samsung Galaxy S25 Ultra (SM-S938U)

Captured by Jacken via PerfProbe on 3.0-ascension, 2026-08-26. ~35 s covering
title → city → E-rank dungeon with combat. This is the FIRST on-device data the
project has ever had; every prior budget was emulator-tuned.

## Headline numbers

| Metric | Value | Reading |
|---|---|---|
| dtMs p50 | 16.7 | 60 fps when clean |
| dtMs p90 / p95 / p99 | 33.3 / 33.3 / 33.4 | ≥10% of frames drop to 30 fps (vsync-bucketed) |
| dtMs max | 50 | one 20 fps hitch (shader compile, see below) |
| frames | 1794 over ~35.3 s | ~51 fps average |
| heap | 53.5 MB flat | no leak across the session |
| tier | ultra throughout | quality.js picked right for this phone |
| reported dpr | 3.75 | **misleading — was the BROWSER's ratio.** The renderer was at ultra's 2.0 cap the whole time. Probe now reports the real render ratio (`dpr`) beside the raw one (`deviceDpr`). |

## Findings → actions

1. **The city is the heavy scene**: ~6× a dungeon's triangles. The 30 fps
   frames concentrate there. Ground rework (Foundation Wave 1) must reduce,
   not add, tri pressure; a city LOD/culling pass is the follow-up if p90
   doesn't recover. (2026-08-26: the sidewalk mesh adds only ~4–6k tris.)
2. **Shader-compile hitching is real**: programs grow 45→115 across the first
   fight — every effect/enemy variant compiles its GLSL the first time it
   appears, which is where the 50 ms max frame lives. ACTION (next perf wave):
   a warm-up compile during the load screen. Must be designed against the
   seeded-RNG contract — enemy spawn paths draw from seeded streams, so the
   warm-up must build render-side objects only, never touch sim spawns.
3. **Resolution is NOT a problem**: ultra renders at pixelRatio 2.0
   (game.js caps at tier.pixelRatio). The probe's old `dpr` field reported
   the raw browser ratio and mis-suggested 3.75; fixed 2026-08-26.
4. **Budget calibration**: city-test's draws p95 ≤ 220 pin is confirmed
   realistic (live worst was 208). dungeon FRAME_BUDGET rows are consistent
   with live combat (131 calls worst at E). No retarget forced by this data.
